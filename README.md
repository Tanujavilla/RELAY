
# RELAY – Intelligent Project Handover System

RELAY is a project handover platform designed to maintain knowledge continuity when a team member leaves a project.

## Features
- Project activity management
- Add, edit and delete activities
- Supabase cloud database integration
- Completed, In Progress and Pending task classification
- Handover report generation
- Handover review and approval
- Downloadable handover reports

## Technology Stack
- Frontend: React, Vite, CSS
- Backend: Node.js, Express.js
- Database: Supabase PostgreSQL
- API: REST API

## Current Limitations
GitHub integration, automated AI analysis and automatic evidence extraction are planned future enhancements.
